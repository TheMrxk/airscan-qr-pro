打包日期：2026-10-22

## 这个包和官方仓库的区别

官方 `index.html` / `airscan-fountain.html` 引用了 4 个外网 CDN
（qrious、jsQR、html5-qrcode、tailwindcss），**在内网/隔离环境打开会白屏**。

本包已把这 4 个库下载到 `vendor/` 并改写引用，新增两个**零外链**的离线页面：

- **`index.offline.html`** —— 单码正式版（离线，推荐先用这个）
- **`airscan-fountain.offline.html`** —— 四码喷泉高速版（离线）
- `index-embedded.html` —— 官方自带的全内嵌单文件版（单码，双击即可用，也完全离线）

已用浏览器实测：两个离线页面所有资源均为本地加载，0 个外部请求。

## 用法

### 方式一：双击打开（最简单）
双击 `index-embedded.html`（单文件，啥都不依赖）或 `index.offline.html`
（需保持 vendor/ 目录同级）。用 Chrome / Edge 打开。

手机端：把整个文件夹（或至少 index-embedded.html）传到手机本地，用手机浏览器打开。

### 方式二：本机 localhost 服务（最稳）
```bash
python3 -m http.server 8000
```
浏览器访问 http://localhost:8000

### 方式三：手机通过局域网访问（需要摄像头 API）
非 localhost 的 HTTP 站点浏览器会禁用摄像头，需走 HTTPS。
证书已随包生成（cert.pem / key.pem，有效期 10 年，CN=localhost）：
```bash
python3 https_server.py
# 手机访问 https://内网IP:4443 ，点"高级 → 继续访问"
```

## 典型流程（从内网电脑往外取文件）

1. 内网电脑打开页面 →「发送」→ 选文件 → 开始（屏幕开始刷二维码）
2. 手机本地打开同一页面 →「接收」→ 摄像头对准屏幕
3. 等进度 100% → 文件落到手机上，完成物理隔离跨越

## 注意

- 单帧容量 200–800 字节，只适合小文件（文本、日志、配置、小图）
- 屏幕调亮、避免反光；喷泉版抗丢帧、速度更快
- 自签证书仅用于内网局域网，不要用于公网
